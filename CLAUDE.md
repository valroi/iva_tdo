# IvaMaris TDO — инструкции для Claude

## Сначала прочитай базу знаний

Проект большой (`documents.py` ~4600 строк). **Не обходи код заново** — начни с
[docs/kb/00-карта/Карта проекта.md](docs/kb/00-карта/Карта проекта.md).

Обязательно к прочтению перед правками:
- `docs/kb/10-домен/Жизненный цикл ревизии.md` — главный процесс
- `docs/kb/10-домен/Роли и права.md` — кто что может
- `docs/kb/40-подводные-камни/Подводные камни.md` — грабли (координаты PDF, автомиграции, время UTC)

`docs/kb` — это vault Obsidian, заметки связаны через `[[ссылки]]`.

## Держи базу актуальной

Меняешь поведение — правь заметку в **том же коммите**. Новое архитектурное решение —
строка в `docs/kb/30-решения/Решения.md` (что решили, почему, дата). Новые грабли —
в `40-подводные-камни/`.

## Рабочие правила проекта

- Перед крупным батчем правок — тег отката: `git tag -a rollback/pre-<тема>-<дата>`.
- Локально: бэкенд на SQLite (`DATABASE_URL="sqlite:///./tdo.db"`), прод — Postgres.
- Миграций Alembic нет: колонки добираются автоматически при старте (только добавление).
- Проверять изменения в браузере под нужной ролью, а не только через API.
- Деплой и откат — `docs/kb/20-архитектура/Деплой и прод.md`.
