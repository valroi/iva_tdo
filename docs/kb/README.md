# База знаний IvaMaris TDO (Obsidian vault)

Эта папка — **vault для Obsidian**. Открой в Obsidian: `Открыть папку как хранилище` → выбери `iva_tdo/docs/kb`.

Зачем: проект вырос, и заново вычитывать код на каждую задачу дорого. Здесь лежит
**граф знаний** — короткие связанные заметки о том, как всё устроено и почему так.
Claude читает эти заметки в начале работы вместо повторного обхода всего кода.

## Как устроено

| Папка | Что внутри |
|---|---|
| `00-карта/` | Точка входа: [[Карта проекта]] — с неё начинать |
| `10-домен/` | Предметная область: роли, статусы, шифры, процесс |
| `20-архитектура/` | Технические узлы: бэкенд, фронтенд, деплой |
| `30-решения/` | Принятые решения и почему (ADR-стиль) |
| `40-подводные-камни/` | Грабли, на которые уже наступали |

## Правила ведения

1. **Одна заметка — одна мысль.** Лучше 10 коротких, чем одна длинная.
2. **Связи важнее текста.** Ссылайся двойными квадратными скобками на имя заметки — граф Obsidian покажет структуру.
3. **Не дублируй код.** Пиши *почему* и *где искать*, а не копии функций. Код меняется, заметка устареет.
4. **Помечай дату** в заметках о состоянии («на 2026-08-07»), чтобы видеть протухшее.
5. **Правь при изменениях.** Меняешь поведение — обнови заметку в том же коммите.
