# Кириллица в PDF

## Факт (проверено движком Chrome — PDFium)

Chrome **не отображает кириллицу во всплывающих заметках** (`/Text` annotations). Файл при этом
корректен: строка пишется в UTF-16BE, PDFium её читает (`FPDFAnnot_GetStringValue` возвращает
`Шифр заменить на "11"`). Не рисуется потому, что PDFium генерирует внешний вид всплывашки
**хардкодным Helvetica**, где кириллических глифов нет. Из PDF на это повлиять нельзя.

Симптом: в жёлтом окне видны только латиница, цифры и `·`/кавычки, русский текст «исчезает».

В Acrobat / Foxit / Preview (macOS) заметки отображаются нормально.

## Что делаем вместо этого

Текст замечаний рисуем **сами** своим юникод-шрифтом:

- панель справа от чертежа со списком замечаний листа (основной способ);
- страница-сводка в конце;
- sticky-заметки оставлены как бонус для десктопных читалок.

Пробовали и отвергли: подписи-плашки поверх чертежа — на плотных листах накладываются друг на
друга и на содержимое (2026-08-07).

## Шрифт

`_register_unicode_font()` ищет по порядку:
`/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` (Docker) → `/Library/Fonts/Arial Unicode.ttf` →
`/System/Library/Fonts/Supplemental/Arial.ttf` → fallback `Helvetica` (кириллицы не будет).

⚠️ В `backend/Dockerfile` обязателен `fonts-dejavu-core`. Уберут — кириллица в экспортном PDF пропадёт.
