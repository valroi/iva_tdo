# ТРМ (транcмиттал)

ТРМ — пакет, которым ревизии передаются заказчику на рассмотрение.

## Нумерация

`{ПРОЕКТ}-{ОТПРАВИТЕЛЬ}-{ПОЛУЧАТЕЛЬ}-TRM-00001`, напр. `IMP-SHP-IVA-TRM-00018`.
Считается как `max+1` по префиксу (`_next_trm_number`). Получатель берётся из справочника
проекта `TRM_RECEIVER_COMPANY_CODE` (по умолчанию `IVA`).

⚠️ Номер выдаётся при отправке. Повторная отправка уже отправленной ревизии раньше
**перевыдавала номер** (номера «прыгали») — теперь гард по статусу, см. [[Идемпотентность и дубли]].

## Где смотреть

- **Страница «ТРМ»** (`TrmRegistryPage`, `GET /trm`) — реестр всех ТРМ по проектам пользователя,
  read-only, доступна всем участникам включая наблюдателя. Раскрытие → ревизии внутри ТРМ.
- **«Очередь ТРМ»** — это другое: очередь рассмотрения у заказчика (не путать).
- Номер ТРМ кликабелен в карточке ревизии и реестре → открывает страницу ТРМ с раскрытым пакетом.

## Сопроводительный лист

`GET /trm/{trm_number}/transmittal.xlsx` — Excel: шапка (№ ТРМ, проект, дата, кол-во документов)
+ таблица `№ / Шифр / Название / Ревизия / Цель выпуска / Статус / Код замечаний`.
Формат согласован по образцу заказчика.
