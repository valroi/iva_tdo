# Фронтенд

React 19 + Vite + antd 5 + react-pdf. Роутера нет — навигация через состояние `activeSection`
в `App.tsx` и синхронизацию с URL-хэшем (`#/revision_card/42`).

## Навигация

- Секции перечислены в типе `Section` и в `validSections` (parseHash) — добавляя страницу,
  правь **оба** места + `sectionTitleMap` + меню.
- Кнопка «Назад» использует **стек истории секций** (`navStackRef` / `goBack`), а не фиксированную
  страницу — иначе выкидывало в «Проекты».
- Глубокие ссылки и «назад» браузера синхронизируются через `popstate`.

## Ключевые страницы

| Файл | Что |
|---|---|
| `DashboardPage` | Обзор: счётчики + «Текущие задачи» (непрочитанные уведомления + очередь заказчика) |
| `ProjectsPage` | Дерево проекта, участники, матрица, реестр, вкладка «Ревизии и комментарии» |
| `DocumentsPage` | Таблица документов + ревизии + замечания (внутри вкладки проекта) |
| `RevisionCardPage` | Карточка документа: этапы, план/факт, иерархия ревизий, замечания |
| `TrmRegistryPage` | Реестр ТРМ + сопроводиловка |
| `RevisionPdfAnnotator` | Модалка PDF: зум, рамки, создание замечаний ([[Замечания и PDF]]) |

## Общие утилиты (переиспользовать!)

- `utils/datetime.ts` — время **хранится в UTC**, показывается в `Europe/Moscow`
  (`parseAsUtc` добавляет `Z` к naive-строкам). Дата-только не сдвигается.
- `utils/pagination.ts` — `paginationProps(key)`: селектор 10/20/30/50/100 + запоминание в localStorage.
- `utils/revisionActions.ts` — матрица «кто что может» по ролям и статусам.
- `utils/revisionProcess.ts` — эффективный код замечаний, отображаемый код ревизии.
- `api.ts` — единая обёртка запросов: 401 → событие `tdo:session-expired` (App покажет
  «Сессия истекла» и вернёт на вход), `docDownloadName()` для имён файлов `шифр_ревизия`.

## Старые браузеры

Часть пользователей на залоченных Chrome < 119 → `src/polyfills.ts` (`Promise.withResolvers`,
нужен pdf.js 5). Импортируется **первым** в `main.tsx`. Не тащить свежие API без полифила.

## Ассеты pdf.js

`scripts/copy-pdfjs-assets.mjs` (хуки `predev`/`prebuild`) копирует из `pdfjs-dist`
каталоги `wasm`, `cmaps`, `standard_fonts` в `public/pdfjs/` (в git не хранятся).
`RevisionPdfAnnotator` передаёт их в `Document` через `wasmUrl`, `cMapUrl` +
`cMapPacked`, `standardFontDataUrl`. Без `wasm` сканы JPEG 2000 выходят пустыми
([[Подводные камни]]).
