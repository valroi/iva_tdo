# Бэкенд

FastAPI + SQLAlchemy. Прод — PostgreSQL, локально удобно SQLite (`DATABASE_URL=sqlite:///./tdo.db`).

## Структура

```
backend/app/
  main.py            сборка приложения, старт демонов
  models.py          ORM-модели (879 строк) — единственный источник схемы
  schemas.py         Pydantic-схемы API
  deps.py            права: default_permissions_for_role, matrix_permission_grants
  database.py        engine + АВТОМИГРАЦИИ (см. ниже)
  routers/
    documents.py     ЯДРО (4600+ строк): ревизии, замечания, CRS, ТРМ, экспорт PDF/Excel
    mdr.py           реестр, шифры, импорт/экспорт Excel
    notifications.py список + автоочистка мусора
    projects.py users.py auth.py workflow.py
    vendors.py vendor_public.py   закупки и внешний портал
    feed.py smart_upload.py       FEED и DocChecker
  services/
    notification_email.py  дублирование уведомлений на почту (after_commit)
    deadline_reminders.py  демон напоминаний о дедлайнах
    review_events.py       журнал действий (ReviewEvent)
```

## Миграции

Alembic **нет**. При старте `database.py` делает `create_all()` + `_ensure_all_model_columns()` —
добирает недостающие колонки по моделям. Поэтому:

- новое поле в модели появляется на проде автоматически после рестарта бэкенда;
- **переименования/удаления не поддерживаются** — только добавление;
- новые таблицы создаются `create_all` (так появились `comment_attachments`).

## Файлы

Загрузки лежат в `UPLOAD_ROOT` (`settings.tdo_uploads_root`), путь пишется в БД
(`Revision.file_path`, `DocumentAttachment.file_path`). При отдаче проверяется, что путь внутри
разрешённых корней (`LEGACY_UPLOAD_ROOTS` — старый `/tmp/tdo_uploads`).

## Тяжёлые зависимости

`openpyxl` (Excel), `pypdf` + `reportlab` (экспорт PDF с замечаниями), `fastembed`/`qdrant`
(RAG для FEED). В Docker дополнительно ставится `fonts-dejavu-core` — иначе кириллица в PDF
не отрисуется.
