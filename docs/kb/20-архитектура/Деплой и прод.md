# Деплой и прод

Прод: **https://ivatdo.ru**, сервер `72.56.242.245` (Timeweb), доступ по SSH-ключу
`~/.ssh/tdo_cloud`, пользователь `deploy`. Docker Compose + Caddy (авто-HTTPS, наружу 80/443).

## Стандартный цикл

```bash
git push origin main
```
```bash
ssh -i ~/.ssh/tdo_cloud deploy@72.56.242.245 "cd ~/iva_tdo && git pull -q && sudo docker compose -f docker-compose.yml -f docker-compose.prod.yml build backend frontend && sudo docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d backend frontend"
```
Смоук после деплоя: `curl -s -o /dev/null -w "%{http_code}" https://ivatdo.ru/` → 200.
Если менялся только фронт/бэк — собирать только его (быстрее).

## Контейнеры

`iva_tdo-backend-1`, `iva_tdo-frontend-1`, `iva_tdo-db-1` (Postgres), `iva_tdo-caddy-1`, `iva_tdo-qdrant-1`.

Логи: `sudo docker logs iva_tdo-backend-1 --tail 20`
БД: `sudo docker exec iva_tdo-db-1 psql -U tdo_app -d tdms -c "SELECT ..."`

## Откат

Перед крупными батчами ставится тег отката:

```bash
git reset --hard rollback/<имя-тега>
```
затем пересборка. Существующие теги: `rollback/pre-batch-20260803`, `pre-batch2-20260804`,
`pre-batch3-20260805`, `pre-batch4-20260806`, `pre-pdfzoom-20260807`.

## Особенности

- **Автомиграции**: новые поля/таблицы применяются при рестарте бэкенда ([[Бэкенд]]).
- **SMTP** настроен (`info@ivatdo.ru`) — уведомления дублируются письмами.
- Локальная разработка идёт на SQLite, прод на Postgres: SQL-специфику не тащить.
