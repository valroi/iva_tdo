# Карта проекта

**IvaMaris TDO** — система документооборота проектной документации (DCC): заказчик (ИваМарис)
рассматривает документы подрядчика, выпускает замечания, ведёт ревизии до финального согласования.

Прод: `https://ivatdo.ru` · сервер `72.56.242.245` (Docker Compose + Caddy) · см. [[Деплой и прод]].

## Модули системы

| Модуль | Что делает | Где код |
|---|---|---|
| **DCC** | Ядро: реестр MDR, документы, ревизии, замечания, CRS, ТРМ | `backend/app/routers/documents.py`, `mdr.py` |
| **Закупки (Vendors)** | Работа с поставщиками, внешний портал по ссылке-приглашению | `routers/vendors.py`, `vendor_public.py` |
| **FEED** | Загрузка и разбор исходных данных FEED, RAG-поиск | `routers/feed.py`, `services/feed_import.py` |
| **DocChecker** | Проверка документов | `routers/smart_upload.py` |

## Ключевые сущности

`Project` → `MDRRecord` (запись реестра, шифр) → `Document` → `Revision` (A, B, 00…) → `Comment` (замечание)

- Реестр MDR ведёт рук. ТДО подрядчика: заводит документ, шифр, плановые даты, вес.
- Вложенные документы: `MDRRecord.parent_id` — программа изысканий под отчётом ([[Вложенные документы]]).
- Замечания живут на ревизии, публикуются подрядчику пакетом CRS ([[CRS и передача замечаний]]).
- У каждого замечания уникальный номер `IMP-RMK-000123` ([[Номера замечаний]]).
- Ревизии группируются в ТРМ (сопроводительный лист) ([[ТРМ]]).
